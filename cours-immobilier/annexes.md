## 1. Glossaire (70 termes essentiels)

| Terme | Définition |
|---|---|
| **ABF** | Architecte des Bâtiments de France. Il donne son avis sur les travaux aux abords des monuments historiques |
| **Acte authentique** | Acte de vente signé devant notaire, qui transfère la propriété |
| **Amortissement** | Constatation comptable de la dépréciation d'un bien, déductible du résultat (LMNP réel, IS) |
| **ANIL / ADIL** | Agence nationale / départementale d'information sur le logement. Conseil juridique gratuit |
| **Apport** | Fonds personnels investis dans l'opération |
| **Art. 1115 CGI** | Régime des droits réduits (0,715 %) pour le MdB qui s'engage à revendre sous 5 ans |
| **Bail mobilité** | Bail meublé de 1 à 10 mois, sans dépôt de garantie, pour un public en mobilité |
| **BIC** | Bénéfices industriels et commerciaux : catégorie fiscale de la location meublée et du MdB en nom propre |
| **Bornage** | Délimitation contradictoire des limites d'un terrain par un géomètre-expert |
| **Capital restant dû (CRD)** | Part du prêt non encore remboursée |
| **Cash-flow** | Solde des encaissements et décaissements d'un investissement |
| **Caution** | Engagement d'un tiers (personne ou organisme) de payer à la place du débiteur défaillant |
| **CFE** | Cotisation foncière des entreprises, due par les loueurs en meublé et les sociétés |
| **Changement d'usage** | Autorisation (CCH, art. L631-7) de transformer un logement en autre chose dans les grandes villes |
| **Clause de substitution** | Permet à l'acquéreur de se faire remplacer par une autre personne (sa société) |
| **Clause résolutoire** | Clause qui résilie automatiquement le bail en cas d'impayé après commandement |
| **Compte à rebours** | Méthode de calcul du prix d'achat maximum à partir du prix de revente |
| **Compte courant d'associé** | Somme prêtée par un associé à sa société |
| **Compromis** | Avant-contrat qui engage réciproquement le vendeur et l'acheteur |
| **Condition suspensive** | Événement dont dépend la réalisation de la vente (prêt, permis…) |
| **CU** | Certificat d'urbanisme (informatif ou opérationnel) |
| **DAACT** | Déclaration attestant l'achèvement et la conformité des travaux |
| **Décote** | Écart entre le prix d'achat et la valeur de marché |
| **Déficit foncier** | Excédent des charges sur les loyers en location nue, imputable jusqu'à 10 700 € sur le revenu global |
| **Démembrement** | Séparation de la propriété entre l'usufruit et la nue-propriété |
| **Destination** | Catégorie d'utilisation d'une construction au sens du Code de l'urbanisme |
| **DIA** | Déclaration d'intention d'aliéner, envoyée à la commune (droit de préemption) |
| **DMTO** | Droits de mutation à titre onéreux (« frais de notaire » hors émoluments) |
| **DO** | Assurance dommages-ouvrage, obligatoire pour le maître d'ouvrage |
| **DP** | Déclaration préalable de travaux |
| **DPE** | Diagnostic de performance énergétique (classes A à G) |
| **DSCR** | Ratio de couverture de la dette : revenu net d'exploitation / annuités |
| **DVF** | Base publique des Demandes de valeurs foncières (prix de vente réels) |
| **EDD** | État descriptif de division (copropriété) |
| **Effet de levier** | Amplification de la rentabilité des fonds propres grâce à l'emprunt |
| **Émoluments** | Rémunération réglementée du notaire |
| **Engagement de construire** | Droit fixe de 125 € pour l'acquéreur qui s'engage à construire sous 4 ans |
| **GFA** | Garantie financière d'achèvement (VEFA) |
| **GLI** | Garantie loyers impayés (assurance) |
| **HCSF** | Haut Conseil de stabilité financière (règles des 35 % et 25 ans) |
| **HLSPD** | Hypothèque légale spéciale du prêteur de deniers (ex-PPD) |
| **Holding** | Société qui détient des participations dans d'autres sociétés |
| **IFI** | Impôt sur la fortune immobilière (au-delà de 1,3 M€ nets) |
| **In fine** | Prêt dont le capital est remboursé en une fois à l'échéance |
| **IRA** | Indemnités de remboursement anticipé |
| **IRL / ILC / ILAT** | Indices de révision des loyers (habitation / commerces / activités tertiaires) |
| **LMNP / LMP** | Loueur en meublé non professionnel / professionnel |
| **Loi Carrez / Boutin** | Surface privative de copropriété (vente) / surface habitable (location) |
| **LTV / LTC** | Dette / valeur du bien ; dette / coût de l'opération |
| **MdB** | Marchand de biens |

| **PPT** | Plan pluriannuel de travaux de copropriété |
| **Promesse unilatérale** | Avant-contrat qui n'engage que le vendeur ; l'acheteur a une option |
| **PS** | Prélèvements sociaux (17,2 % sur les revenus fonciers et les plus-values immobilières) |
| **Réception** | Acceptation des travaux par le maître d'ouvrage, point de départ des garanties |
| **Rendement brut / net** | Loyers / prix ; (loyers − charges) / coût total |
| **SCCV** | Société civile de construction-vente (promotion) |
| **SCI** | Société civile immobilière |
| **SPS** | Coordination sécurité et protection de la santé sur les chantiers |
| **Tantièmes** | Quote-parts de parties communes attachées à chaque lot de copropriété |
| **TMI** | Tranche marginale d'imposition |
| **TRI / VAN** | Taux de rendement interne / valeur actuelle nette |
| **TVA sur marge** | TVA calculée sur la différence entre le prix de vente et le prix d'achat (art. 268 CGI) |
| **Usufruit** | Droit d'utiliser un bien et d'en percevoir les revenus |
| **VEFA** | Vente en l'état futur d'achèvement (achat sur plan) |
| **VIR** | Vente d'immeuble à rénover (régime protecteur d'ordre public) |
| **VNC** | Valeur nette comptable (valeur d'origine − amortissements) |

## 2. Formulaire

```
Rendement brut           = Loyer annuel HC / Prix d'achat
Rendement brut global    = Loyer annuel HC / (Prix + notaire + travaux + mobilier)
Rendement net            = (Loyers encaissés − charges non récupérables − TF − gestion − PNO) / Coût total
Cash-flow                = Loyers encaissés − charges − mensualités (capital + intérêts + assurance) − impôts
Mensualité               = C × i / (1 − (1 + i)^−n)            i = taux annuel/12, n = nombre de mois
Capacité d'emprunt       = M × (1 − (1 + i)^−n) / i
Taux d'effort (HCSF)     = Mensualités de crédit (assurance incluse) / Revenus nets   ≤ 35 %
Levier                   ROE ≈ R + (R − i) × D / FP
DSCR                     = Revenu net d'exploitation / Annuités de la dette           ≥ 1,2
Valeur par capitalisation = Loyer net / Taux de capitalisation
Prix max (investisseur)  = Loyer annuel / Rendement brut visé − frais − travaux
Prix max (MdB)           = (Prix de vente − frais de vente − marge cible − travaux − frais) / (1 + frais d'acquisition)
TVA sur marge            = (Prix de vente − Prix d'achat) × 20 / 120
Frais de notaire ancien  ≈ 7,5 à 8,5 % ; neuf ≈ 2 à 3 % ; MdB (art. 1115) ≈ 2 à 2,5 %
Plus-value particuliers  = 19 % IR + 17,2 % PS, avec abattements (exonération IR 22 ans, PS 30 ans)
IS                       = 15 % jusqu'à 42 500 €, 25 % au-delà
```

Fonctions Excel : `VPM` (mensualité), `VA` (capacité), `TRI`, `TRI.PAIEMENTS`, `VAN`, `PRINCPER` et `INTPER` (part de capital et d'intérêts d'une échéance).

## 3. Checklists opérationnelles

### 3.1 Due diligence avant l'offre
- [ ] Comparables DVF (vente) et loyers de marché (location).
- [ ] Visite technique avec un professionnel ; devis ou estimation des travaux.
- [ ] DPE et coût pour atteindre la classe cible.
- [ ] PLU : zone, destination, règles de stationnement, emprise, hauteur ; servitudes (ABF, PPRI).
- [ ] Copropriété : règlement, 3 derniers PV d'AG, charges, fonds de travaux, PPT, procédures, impayés.
- [ ] Situation locative : baux, loyers, impayés, dépôts de garantie, date d'échéance.
- [ ] Cadastre et bornage (maison, terrain), accès, réseaux.
- [ ] Motivation du vendeur et historique de mise en vente.
- [ ] Business plan et stress tests dans le simulateur.

### 3.2 Avant la signature du compromis / de la promesse
- [ ] Clause de substitution au profit de ta société.
- [ ] Conditions suspensives : prêt (montant, taux, durée), urbanisme purgé, préemption, copropriété.
- [ ] Engagement de revendre (MdB) prévu pour l'acte.
- [ ] Ventilation mobilier, liste annexée.
- [ ] Date butoir de réitération compatible avec la banque et les autorisations.
- [ ] Diagnostics annexés et lus (amiante, plomb, termites, électricité).

### 3.3 Dossier bancaire
- [ ] Fiche synthèse d'une page.
- [ ] Présentation de l'emprunteur et de sa structure (organigramme).
- [ ] Business plan, plan de trésorerie, stress tests.
- [ ] Comparables, devis, photos, plans.
- [ ] Compromis ou promesse.
- [ ] Pièces personnelles : identité, revenus, avis d'imposition, relevés, tableaux d'amortissement.
- [ ] Pièces de société : Kbis, statuts, 2 ou 3 derniers bilans, liasse fiscale.

### 3.4 Création d'une SCI
- [ ] Choix des associés, de la répartition et du régime fiscal (IR / IS).
- [ ] Statuts sur mesure : objet large, gérance, pouvoirs, agrément, démembrement, majorités.
- [ ] Dépôt du capital, annonce légale, immatriculation via le guichet unique, bénéficiaires effectifs.
- [ ] Compte bancaire, option IS éventuelle (dans les 3 mois du début de l'exercice), expert-comptable.
- [ ] Registre des décisions, calendrier des AG.

### 3.5 Lancement d'une activité de MdB
- [ ] Création de la SAS (sous holding), code NAF 68.10Z, régime réel de TVA.
- [ ] Expert-comptable spécialisé (TVA immobilière).
- [ ] Banque professionnelle, ligne de financement MdB.
- [ ] Assureur : RC, DO, éventuellement CNR (assurance constructeur non réalisateur) pour les opérations lourdes.
- [ ] Réseau de sourcing (agents, notaires) et équipe travaux.
- [ ] Modèle de bilan d'opération standardisé (simulateur).

### 3.6 Mise en location
- [ ] Décence et DPE (G interdit, gel des loyers F/G).
- [ ] Diagnostics location, surface Boutin.
- [ ] Liste des meubles (meublé).
- [ ] Loyer conforme (zone tendue, encadrement).
- [ ] Annonce avec mentions obligatoires.
- [ ] Sélection conforme au décret de 2015 (pièces), sans discrimination.
- [ ] Garantie (Visale, GLI ou caution).
- [ ] Bail type + annexes, état des lieux détaillé et photographié.
- [ ] Assurance habitation du locataire, PNO.
- [ ] Immatriculation LMNP (P0i) le cas échéant, déclaration de meublé de tourisme / numéro d'enregistrement.

## 5. Veille à mettre en place (15 minutes par jour)
- Alertes Google sur « loi de finances immobilier », « LMNP », « marchand de biens TVA », « DPE location ».
- Newsletters de l'ANIL et d'une revue professionnelle (droit immobilier, fiscalité patrimoniale).
- Suivi mensuel des taux (Crédit Logement/CSA) et des prix (baromètre des notaires).
- Chaque automne : lecture du **projet de loi de finances** et de la **LFSS** (volet immobilier), puis mise à jour de tes modèles en janvier.
